# Japan Travel Itinerary Builder

An interactive travel itinerary generator for Japan. Enter a destination, budget level, travel month, and number of days to generate a personalized day-by-day itinerary, powered by the Claude API.

Live Demo
https://elizabeth-shin.github.io/japan-travel-itinerary-generator/

## How It Works

1. Type in a destination (Tokyo, Kyoto, Osaka, Hokkaido, or anywhere else in Japan)
2. Choose your budget level: Economy, Moderate, or Premium
3. Select your travel month
4. Choose trip length: 1, 2, 3, 4, 5, or 7 days
5. Click "Generate Itinerary" to see your personalized, Claude-generated plan
